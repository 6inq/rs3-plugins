# 6ing's RS3 Plugins

The hub for my RuneScape 3 plugins for the official Plugin Hub (hosted on [mod.io](https://mod.io/g/runescape)). Each plugin lives in its own repository; this repo is the index.

## Plugins

| Plugin | Version | What it does | Repo |
|---|---|---|---|
| Bank Organizer | 1.4.2 | Colour-codes your bank by category and guides you through sorting it, one move at a time, with custom categories and tags and a Bank Cleaner. | [6inq/bank-organizer](https://github.com/6inq/bank-organizer) |
| WhereAmIFacing | 1.1.2 | An arrow at your character's feet showing which way you face (N, NE, E, SE, S, SW, W, NW), in any colour. | [6inq/whereamifacing](https://github.com/6inq/whereamifacing) |
| ZukFireLines | 1.0.2 | Highlights TzKal-Zuk's fire lines on the floor as they sweep across the arena, 3 or 5 tiles wide, in any colour. | [6inq/zukfirelines](https://github.com/6inq/zukfirelines) |
| Auto Screenshot | 1.0.2 | Screenshots level-ups (all, 99s, 120s, both, or broadcasts only), achievements, rare drops and your broadcasts. | [6inq/autoscreenshot](https://github.com/6inq/autoscreenshot) |

## Working locally
Clone the hub, then clone each plugin inside it (plugin folders are git-ignored here):

```bash
git clone https://github.com/6inq/rs3-plugins.git
```

```bash
git clone https://github.com/6inq/bank-organizer.git rs3-plugins/bank-organizer
```

```bash
git clone https://github.com/6inq/whereamifacing.git rs3-plugins/where-am-i-facing
```

